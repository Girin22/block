# BlockStep

곡선 인터로킹 블록으로 나만의 길을 쌓는 모바일 중심 미니멀 게임. 현재 저장소는 **V2 웹 프로토타입만** 포함합니다. Vite + TypeScript + Three.js로 실행되며 서버·로그인·DB가 없습니다.

## 실행

Node.js 22.12 이상을 사용합니다. Windows PowerShell에서는 `npm.cmd`로 실행할 수 있습니다.

```sh
npm ci
npm run dev
npm run test
npm run build
```

개발 주소는 `http://localhost:5173/`입니다. 휴대폰은 PC와 같은 Wi-Fi에서 개발 서버에 표시된 `Network` 주소로 접속하세요. PC와 서버가 켜져 있어야 합니다.

## 플레이

- 첫 타일을 터치하면 자동 낙하가 시작됩니다. 잡고 있는 동안은 멈춥니다.
- 아래·좌우로 끌어 배치하고 탭하면 회전합니다. 위로 끌어올릴 수는 없습니다.
- 아래로 48px 이상, 가로보다 세로 이동이 큰 스와이프와 기존 75% 높이 조건을 만족하면 빠르게 안착합니다.
- 블록으로 완전히 둘러싸인 빈 공간은 크기와 상관없이 흰 타일(1×1, 2×1, 1×2)로 아래에서 위로 차례차례 채워집니다. 화면 아래로 지나간 공간도 닫히면 끝까지 채웁니다. 카메라는 쌓인 높이를 따라 이동합니다.
- 최대 172,800개까지 배치합니다. 흰 자동 타일은 제외하며, 0.5초당 1개 × 24시간으로 계산한 **개수 제한**입니다.
- 일시정지하면 깔린 길이(미터)·블록 수·내보내기가 아래에서 올라옵니다. 재개는 글씨 없이 고깔로 바뀐 오른쪽 위 아이콘을 다시 누릅니다. 제한 도달 시 추가 배치는 멈추고 Export는 사용할 수 있습니다.
- 새로고침하거나 화면을 완전히 나가면 새 게임입니다. 진행 상태를 영구 저장하지 않습니다.
- 모든 블록은 가운데 열에서 세로 방향으로 시작합니다.
- 키보드 테스트: ←/→ 이동, ↑ 회전, ↓/Space 배치. 자동 플레이 차단은 없습니다.
- 관리자 모드: 주소 뒤에 `?admin`을 붙이면 게임 화면 바깥에 ‘비 내림’ 버튼이 나타납니다. 연출 전용이며 규칙·조각 수·Export에는 영향이 없습니다.

## 사진 저장

일시정지 화면의 ‘내보내기’를 누르면 전체 패턴을 배경이 투명한 가로 688px PNG 한 장으로 바로 저장합니다. 미리보기 팝업은 뜨지 않으며, 저장이 끝나면 새 세션으로 이어집니다. 3,200만 픽셀 또는 세로 65,536px를 넘으면 축소 대신 SVG 파일 한 장으로 전환합니다.

예전의 영수증 미리보기 팝업은 레거시로 남겨 두었고 주소 뒤에 `?receipt`를 붙였을 때만 열립니다. 브라우저 검증 스크립트가 이 화면으로 배치 결과를 읽습니다.

PC와 안드로이드에서는 다운로드 폴더에 저장됩니다. 아이폰 사파리는 다운로드를 파일 앱에 저장하므로 사진 앱으로 옮기려면 파일 앱에서 공유해야 합니다. 실제 기기의 저장/확대 한계는 별도 확인이 필요합니다.

## 구조

```text
apps/play/src/         화면·입력·3D·효과음·영수증
packages/play-core/    게임 규칙과 세션 상한
tests/                 V2 단위 테스트
scripts/               브라우저 검증 스크립트
public/                배포 정적 자산
assets/                향후 원본 자산
docs/                  규칙·검증·배포 문서
index.html             유일한 빌드 진입점
```

## 배포

Vercel에서 저장소 루트를 선택하고 Framework `Vite`, Build `npm run build`, Output `dist`로 배포합니다. 현재 환경변수는 필요 없습니다. 자세한 설정은 [V2 배포 안내](docs/deployment.md)를 참고하세요.

기존 V1은 원래 PC에만 보관하고 Git 및 기본 빌드·테스트에서 제외했습니다. V2는 레거시 코드 없이 동작합니다. 레거시는 GitHub에 백업되지 않으므로 필요하면 별도 백업하세요.

규칙: [미니멀 V2](docs/minimal-v2.md) · 이미지 출력: [고해상도 한 장 저장](docs/highres-export.md)

네이티브 앱·만보기 연동·PWA는 아직 구현하지 않았습니다.
