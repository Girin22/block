CSS 화면 크기 기준 근사치입니다. 앱은 상태 표시줄(안드로이드는 아래 내비게이션 바도)을 숨기므로 점선으로 자리만 표시합니다. ‘상태 표시줄 펼침’은 위에서 쓸어내렸을 때의 모습입니다. 카메라 구멍과 다이내믹 아일랜드는 항상 화면을 가립니다. ‘온보딩 자동 진행’은 온보딩 ‘봤음’ 표시를 지우고 모든 기기를 새로 연 뒤, 가상 사용자가 동시에 시작하기 → 탭 회전 → 옆 스와이프 → 아래 스와이프 → 빨간 버튼 안내가 나오면 일시정지 → 새로 쌓기까지 진행해 빈 판에서 멈춥니다(손짓은 화면에 표시만 하고 실제 입력은 키보드 조작으로 보냅니다). 실제 안전 영역 값은 에뮬레이터나 실기기에서 확인하세요. 소리는 각 화면을 한 번 눌러야 시작합니다.
